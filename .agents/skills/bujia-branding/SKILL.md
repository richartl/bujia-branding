# Branding de Bujía

Sigue la secuencia de [AGENTS.md](../../../AGENTS.md). Consulta la [guía visual](../../../BRAND_GUIDELINES.md) para la jerarquía de referencias, el color, la preservación del estilo y las restricciones de acabados. Busca las fuentes reales en el [catálogo](../../../CATALOG.md) y aplica la [protección de maestras](../../../masters/README.md).

El [protocolo](../../../docs/IMAGE_EDITING.md) define `STRICT_EDIT`, `CONTROLLED_VARIATION` y `CREATIVE_GENERATION`. Usa las [plantillas de prompts](../../../prompts/) internamente. Consulta [versionamiento](../../../docs/VERSIONING.md), [revisión](../../../docs/APPROVAL_CHECKLIST.md), [aprobación y registro](../../../docs/ASSET_WORKFLOW.md) y [producción](../../../docs/PRINT_PRODUCTION.md) según el trabajo.

Para usar estas instrucciones sin activación automática o resolver el acceso a imágenes, sigue la [guía de inicio](../../../docs/GETTING_STARTED.md).

Aplica la [regla de entrega de propuestas](../../../docs/IMAGE_EDITING.md#entrega-de-propuestas) y muestra cada imagen al propietario para revisión.

Para todo sticker aplica la regla de [logo, Instagram y silueta](../../../docs/IMAGE_EDITING.md#logo-instagram-y-silueta-de-stickers).

Para cualquier diseño de fachada, consulta la [regla de fachada actual](../../../BRAND_GUIDELINES.md#fachada-actual).
