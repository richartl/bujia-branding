# Revisión visual

Compara la candidata con el archivo exacto y con las referencias pertinentes. Marca cada punto como conforme, desviado, no aplicable o sin verificar según lo observado.

- [ ] Se conservan carácter artesanal, grosor del trazo e irregularidad natural.
- [ ] Se mantienen proporciones, expresión, silueta y composición donde corresponde.
- [ ] Texturas, fondo y objetos protegidos permanecen como en la fuente.
- [ ] Los colores y los cambios se limitan a lo autorizado.
- [ ] El resultado carece de brillos, reflejos, sombras, degradados o adornos nuevos sin autorización.
- [ ] El resultado pertenece a la misma familia gráfica cuando corresponde.
- [ ] La ficha registra procedencia, maestra y versión exacta de origen.
- [ ] El archivo original permanece intacto y la variante tiene una ruta propia.

Muestra la fuente y la candidata juntas cuando sea posible. Expón las desviaciones y lo que no pudiste inspeccionar. Si comparaste visualmente, describe similitud visual. Reserva las afirmaciones de igualdad exacta para comprobaciones que la demuestren. La decisión corresponde al propietario y se registra según el [flujo de aprobación](ASSET_WORKFLOW.md).
