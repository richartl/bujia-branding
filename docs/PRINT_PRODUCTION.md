# Preparación para impresión y otros medios

Parte de la versión aprobada o identificada para revisión. Conserva la maestra y crea un derivado en [exports](../exports/) según el destino. Mantén trazos y proporciones, limita los cambios a los requisitos confirmados y conserva transparencia cuando corresponda. Registra fecha, versión, dimensiones finales, resolución efectiva si es raster, formato, tintas, soporte y verificaciones en la [ficha de diseño](../templates/design.md).

| Uso | Criterios que debes verificar |
| --- | --- |
| Serigrafía a una tinta | Una separación, contraste sobre el sustrato, grosor mínimo y zonas negativas. Evita degradados sin un proceso de tramado confirmado. |
| Serigrafía a dos tintas | Dos separaciones y orden de tintas. Confirma registro, sobreimpresión y base si aplican, antes de preparar los archivos de separación. |
| Impresión digital | Tamaño final, resolución efectiva, formato y perfil de color aceptado por el proveedor. |
| Stickers y packaging | Troquel, sangrado, margen de seguridad, acabado y capas requeridas. |
| Playeras, totebags y gorras | Área imprimible, material, color del soporte, colocación y técnica. |
| Bordado | Tamaño de puntada y grosor mínimo según el proveedor. La digitalización para bordado requiere un archivo y una comprobación específicos. |
| Flyers, posters y señalética | Medidas finales, margen, sangrado si aplica y legibilidad a la distancia de uso prevista. |
| Redes sociales y web | Relación de aspecto, tamaño, recorte, legibilidad y formato admitido. |

Cada carpeta de exportación corresponde a un destino: `screen-printing`, `digital-printing`, `embroidery`, `social-media` o `web`. Un PNG sigue siendo raster aunque tenga fondo transparente. Verifica el contenido de un archivo antes de llamarlo vectorial. Cuando falten especificaciones del proveedor, registra los datos pendientes y presenta el archivo como prueba. Declara preparación para producción únicamente tras comprobar las especificaciones correspondientes.

Para stickers aplica el [formato de corte](IMAGE_EDITING.md#formato-de-corte) y verifica que el logo e Instagram queden dentro del perímetro. El canal alfa del PNG muestra el exterior transparente de una silueta. Si la imprenta requiere una línea vectorial de corte, prepárala con el formato, el margen y el sangrado que indique.
