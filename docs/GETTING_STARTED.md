# Primeros pasos

1. Coloca los originales en [inbox](../inbox/) o adjúntalos a la conversación.
2. Pide al agente que los organice. Si una imagen debe registrarse como maestra, indícalo expresamente y aporta su procedencia si la conoces. El agente sigue el [flujo de incorporación](ASSET_WORKFLOW.md) y actualiza el [catálogo](../CATALOG.md).
3. Pide una edición con lenguaje natural. Ejemplo hipotético: «Usa la versión de la jirafa que te adjunto. Cambia únicamente la taza de verde a amarillo y guarda una variante para revisión».
4. Revisa la comparación con la fuente y comunica qué versión apruebas. Consulta cómo [recuperar versiones](VERSIONING.md) o [preparar una adaptación para impresión](PRINT_PRODUCTION.md).

## Acceso según el agente

| Agente | Cómo empezar |
| --- | --- |
| Codex | Abre una tarea sobre la copia del repositorio. Pídele que lea [AGENTS.md](../AGENTS.md) y use la [skill](../.agents/skills/bujia-branding/SKILL.md). |
| ChatGPT | Usa el acceso a GitHub cuando esté disponible o adjunta la guía, la ficha y la imagen exacta. Comprueba que la herramienta de edición recibe la imagen como referencia visual. |
| Claude | En una sesión con acceso al repositorio, indica que siga [CLAUDE.md](../CLAUDE.md). En chat, adjunta los documentos y las referencias necesarias. |
| Otros agentes | Abre [AGENTS.md](../AGENTS.md) y proporciona los documentos enlazados junto con los originales relevantes. |

Si la skill no se activa automáticamente, pide que abra su [SKILL.md](../.agents/skills/bujia-branding/SKILL.md) y siga los documentos enlazados. GitHub conserva el historial, pero el acceso a texto del repositorio puede no incluir acceso visual a binarios ni transferencia a una herramienta gráfica. Adjunta la fuente exacta si el agente no puede verla. Si el agente carece de edición o generación, puede ayudar con el catálogo, la ficha o el pedido para una sesión que sí disponga de esas funciones. La edición generativa puede alterar zonas ajenas al cambio, por lo que requiere comparación con el original. La skill por sí sola no garantiza fidelidad exacta.

Al solicitar propuestas, recibirás una imagen por opción y podrás ver cada una en la respuesta cuando la sesión lo permita. Puedes pedir una lámina comparativa de forma expresa. Consulta la [regla de entrega](IMAGE_EDITING.md#entrega-de-propuestas).
