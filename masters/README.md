# Imágenes maestras

Aquí se conservan originales de identidad reutilizables con aprobación explícita del propietario. Una aprobación de uso en un producto no convierte el diseño en maestra.

Guarda el original en su formato y resolución disponibles con una ficha Markdown del mismo nombre. Nunca sobrescribas una maestra ni la sustituyas por una reinterpretación. Su eliminación o regeneración requiere autorización expresa. Crea archivos derivados independientes para retoques, transparencia, vectorización e impresión y conserva todas las versiones con su relación de origen.

| Ubicación | Uso |
| --- | --- |
| [logo](logo/) | Versiones oficiales del logotipo. |
| [illustrations/human](illustrations/human/) | Obra humana original y primera referencia estilística. |
| [illustrations/ai-generated](illustrations/ai-generated/) | Obra generada con IA y aprobada expresamente como maestra. |
| [illustrations/hybrid](illustrations/hybrid/) | Obra que combina trabajo humano y generativo. |
| [illustrations/unknown](illustrations/unknown/) | Obra de procedencia aún sin confirmar. |
| [photography](photography/) | Fotografías maestras. |
| [textures](textures/) | Texturas maestras. |
| [typography](typography/) | Archivos tipográficos autorizados según sus derechos de uso. |

Las carpetas `characters`, `objects`, `scenes`, `facade` y `graphic-elements` agrupan personajes, objetos, escenas, fachada y elementos gráficos. Registra la procedencia aunque el tipo de archivo determine su carpeta. Usa `human`, `ai-generated`, `hybrid` o `unknown`. La apariencia visual por sí sola no acredita el origen. La procedencia es independiente de la aprobación.

Consulta el [flujo de incorporación](../docs/ASSET_WORKFLOW.md) y la [plantilla de ficha](../templates/asset.md).
